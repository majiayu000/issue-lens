## 输入和证据范围

- 产品输入来自五个本地公开项目的 README 快照。[输入清单](inputs/manifest.json)记录了仓库链接、本地版本、输入路径及 SHA-256；remem 使用清单中列出的完整章节，其余使用完整 README。
- 原始语料于 2026-09-23 采集，包含 79 个仓库、30,784 条 issue：CLI 16,054 条，桌面 14,730 条。生成方案时没有重新抓取 GitHub。
- 每个产品选入 12 条候选，共 60 条不同候选。只有适用的案例进入最终建议；“关键词匹配”不等于“可以迁移”。
- 语料包含 issue 标题、正文和标签；**尚未采集关联 PR 的正文、补丁或评论**。正文发送给模型时最多取前 12,000 字符，截断状态保留在 JSON。
- closed、linked:pr、completed 是筛选条件，不证明该条目一定是 bug，也不证明根因。未知根因保留为空，功能请求与 bug 分开标注。
- 当前每份最多提取 8 个需求主题，使用英文 FTS 关键词检索。15 个仓库在原始采集中有截断标记；本批不能视为所有 GitHub issue/PR 或完整 PRD 验收清单。

## 执行前需要明确的产品边界

以下来自所给 README 的版本区分或表述歧义，尚未通过产品实现裁决：

- **rekey**：选择已发布 Alpha 还是当前源码作为测试目标，尤其要区分状态/备份格式和源码专属能力。
- **remem**：实验性上下文包、未完成的过滤边界及安全控制台的发布条件，需要固定验收版本。
- **rclean**：默认删除去向的 Trash/graveyard 表述、模型目录的 caution/report-only 分类及 `free` 的优化目标需要明确。
- **quotabar**：通知运行时与静态预览的边界、通知阈值口径，以及认证失败的自动重试/手动复查条件需要明确。
- **dsh-desk**：固定源码组合或已发布安装包组合；“60 seconds”仍是目标，不能直接作为已验证基准。

## 用同一输入再生成一份

在 issue-lens 仓库根目录运行，输出路径必须尚不存在：

```bash
export ISSUE_LENS_LLM_ENGINE=codex
python3 s05_plan.py --form cli \
  --prd out/five-products-20261001/inputs/rekey.md \
  --out out/rekey-next.md --limit 12
```

本批使用已登录的 Codex CLI 默认模型，未指定模型名；各次调用的 thread ID、token usage 及提炼来源记录保存在对应 JSON 中。模型输出存在随机性，复用输入不保证产生相同方案。
