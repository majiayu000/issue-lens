# 怎么判断 Issue Lens 有没有用

## 要回答的问题

Issue Lens 只承诺一件事：**给它一段要测的代码，它借助其他项目的历史 issue，提出模型单独读代码想不到、但能抓到真实 bug 的测试点。** 其他价值（灵感、覆盖、学习材料）都不能单独作为保留它的理由。

决定：继续把 Issue Lens 当作测试生成的增强工具投入，还是只保留为数据集。

> **2026-10-22 第一次结果：否定。** 49 道题，A、B 都命中 15 道，提升 0 个百分点（95% 置信区间 [−8.2, +8.2]），B 的输入 token 是 A 的 2.06 倍。详见 [out/backtest-20261022](../out/backtest-20261022/README.md)。

## 回测：用已修复的 bug 当考题

语料里每条带修复 PR 的 bug 都是一道有答案的题，不需要维护者评价：

1. **出题**：选一个已修复的 bug，取修复 PR 改动的源码文件在修复前的版本（合并提交的第一个父提交），加上仓库简介。issue 正文、PR 和补丁都不给。
2. **A 组**：模型只读这些代码，提出 5 条测试。
3. **B 组**：同样的输入；模型先根据代码提出检索词，再从语料中检索。只能检索**比这个 bug 更早创建**、**不属于同一仓库**、分层为 core/usable 的 issue。之后模型参考这些历史，提出 5 条测试。
4. **判分**：另一次模型调用读取真实 issue 和修复补丁，在不知道组别的情况下逐条判断：
   - `hit`：按这条测试在修复前的代码上执行，会因为这个 bug 失败（触发条件和可观察结果都对得上）。
   - `mechanism`：指出了同一个故障机制（为什么会错），但步骤或断言不足以稳定触发。只测到同一函数或区域、机制不同的不算。
   - `miss`：其他情况。
5. **防止凭记忆答题**：只选 2026-04-01 之后创建并修复的 bug。模型自报的知识截止日期不能作为依据，所以这条只能降低、不能排除记忆的影响。

已知偏差：只给被修复的文件，等于告诉了模型 bug 在哪个文件里。这会让两组的命中率都偏高；A 和 B 拿到相同的提示，所以差值仍然可以比较。

## 指标

| 指标 | 定义 |
|---|---|
| 命中率（主指标） | 至少一条测试被判为 `hit` 或 `mechanism` 的题目比例，A、B 分开计算 |
| 严格命中率 | 至少一条测试被判为 `hit` 的题目比例 |
| 提升 | B 命中率 − A 命中率；配对题目做 bootstrap，给出 95% 置信区间；同时报告 McNemar 精确检验 |
| 独有命中 | 只有 B 命中的题数和只有 A 命中的题数 |
| 归因 | B 组命中的测试里，引用了历史 issue 的比例 |
| 成本 | B 比 A 多用的输入 token 和耗时 |

判分模型的可靠性另行抽查：人工复核其中一部分判断，记录一致率。

## 试跑后的调整（正式运行前定下）

两轮共 6 道试跑题，A、B 两组的严格命中都是 0：给整个文件时，5 条测试散落在无关函数上；不少题是纯样式修复，读代码本来就写不出能抓到它的测试。因此正式运行前改了三处：

1. 只给改动位置前后各 80 行（“审查这段代码”的场景），两组提示仍然相同。
2. 排除只改 CSS/HTML 等样式文件的修复；题目按产品形态轮流选取。
3. 主指标从严格命中改为“命中或指出同一故障机制”，严格命中作为辅助指标。

试跑的 6 道题已用于调参，不进入正式题集。

## 放弃条件（跑之前写定）

用 50 道题：

- **否定**：提升 < 5 个百分点，或者 95% 置信区间包含 0。结论是 Issue Lens 不作为测试生成增强工具继续投入，语料保留为数据集。
- **采用**：提升 ≥ 5 个百分点，置信区间不包含 0，并且 B 独有命中里至少一半引用了机制相同的历史 issue。
- **待验证**：介于两者之间，或者人工复核时判分一致率低于 80%。这时扩大到 100 题，或者改用可执行判分（生成测试在修复前失败、修复后通过）。

## 之后怎样变成持续运转的系统

只有回测结论不是“否定”时才值得做：

1. 每周增量拉取已收录仓库新关闭的 issue，重算 `s07_quality.py` 分层。
2. 上周新修复、分层为 core 的 bug 自动变成新考题。它们天然晚于模型训练时间，题库会随时间变大。
3. 任何对来源、分层规则或检索方式的修改，都要在固定题集上重跑；提升不下降才合入。每个语料版本记录一次提升数值。

运行方法和每次结果见 `experiments/backtest.py` 与 `out/backtest-*/README.md`。
